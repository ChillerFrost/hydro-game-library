1Hydro — game library web app
Assumptions. Browser web app at 1440×900; static mock; games come from a curated Hydro catalogue; library features shown are install/play state, collections & tags, search & filters. Steam was the reference for scope, but the visuals are original: deep charcoal surfaces, a single aqua accent (Hydro), Sora for display type, IBM Plex Sans for UI.
Reasoning. Three library layouts differ on one axis — how much the selected game dominates: 1a list + always-visible detail (fast switching), 1b cover grid (browsing a big library), 1c shelves grouped by state and collection (surfaces what to play next). Supporting screens below share the same nav and components so any option plugs in.
Placeholders. Cover art and screenshots are striped/gradient placeholders with fictional titles — drop real images in later.
